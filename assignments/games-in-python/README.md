# 📘 Assignment: Jogo da Forca

## 🎯 Objetivo

Pratique manipulação de strings, loops, condicionais e entrada de dados em Python criando um jogo em que o jogador tenta adivinhar uma palavra oculta.

## 📝 Tarefas

### 🛠️ Implementar os palpites de letras

#### Descrição
Crie uma rodada do jogo que escolha aleatoriamente uma palavra de uma lista predefinida e permita ao jogador adivinhar suas letras.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatoriamente de uma lista predefinida
- Aceitar palpites de letras do jogador
- Mostrar o progresso da palavra oculta, usando espaços reservados como `_ _ _`


### 🛠️ Controlar o encerramento do jogo

#### Descrição
Mantenha o controle dos palpites incorretos e encerre a rodada quando o jogador adivinhar a palavra ou esgotar as tentativas.

#### Requisitos
O programa concluído deve:

- Rastrear e exibir as tentativas incorretas restantes
- Encerrar o jogo quando a palavra for adivinhada ou as tentativas se esgotarem
- Exibir uma mensagem indicando vitória ou derrota
